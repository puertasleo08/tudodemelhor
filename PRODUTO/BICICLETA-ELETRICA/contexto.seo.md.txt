## 5. Diretrizes de Geração e SEO (Regras de Ouro)
- **NEURONwriter (MCP):** É obrigatório o uso do MCP do NEURONwriter para otimizar a redação. O conteúdo final deve atingir um **Score de 80+**, garantindo a inserção semântica da palavra-chave primária e das adicionais listadas na Seção 2.
- **Meta Tags:** O Meta Title e a Meta Description devem ser gerados com foco agressivo na Palavra-chave Primária, otimizados para atrair o clique (alto CTR).
- **SEO de Imagens:** Todas as tags `<img src="...">` geradas no HTML devem obrigatoriamente conter o atributo `alt` preenchido. O texto alternativo deve ser descritivo e incorporar as palavras-chave indicadas na Seção 2 de forma natural.
- **Estrutura:** O código deve respeitar a estrutura de listagem, utilizando a classe `.glass` e o design system do `tudodemelhor.com.br`.
- Uso do Firecrawl (Data Scraping): Acesse as URLs dos links de afiliado fornecidos na Seção 3 utilizando o Firecrawl. Extraia a ficha técnica real, as funcionalidades e leia os comentários dos compradores para formular os blocos de "Prós e Contras" e a "Análise Detalhada" com extrema precisão e veracidade.

## 6. Galeria de imagens (`imagens_galeria`)

Campo opcional em cada produto da Seção 3. As URLs aparecem como miniaturas (60×60 px) abaixo do botão "Comprar no Mercado Livre" nas páginas `review-*.html`.

**Formato no contexto (por produto):**

```yaml
- imagens_galeria:
  - url: https://http2.mlstatic.com/foto-principal.webp
    alt: Descrição SEO da foto (obrigatório para acessibilidade)
  - url: https://http2.mlstatic.com/foto-detalhe.webp
    alt: Outro ângulo do produto
```

**Atalho (só URL):** se omitir `alt`, o gerador cria automaticamente "Foto N — Marca Modelo":

```yaml
- imagens_galeria:
  - https://http2.mlstatic.com/foto-1.webp
  - https://http2.mlstatic.com/foto-2.webp
```

**Lista vazia** (sem galeria na página):

```yaml
- imagens_galeria: []
```

**Como chega no HTML:** copie o array para o campo `galleryImages` do produto em `scripts/generate_bike_reviews_philco.mjs` e rode `node scripts/generate_bike_reviews_philco.mjs`. Exemplo:

```javascript
galleryImages: [
  { url: 'https://http2.mlstatic.com/foto-1.webp', alt: 'Oimotoo S6 dobrável — vista lateral' },
  'https://http2.mlstatic.com/foto-2.webp'
],
```

Use URLs diretas de imagem (`.webp`, `.jpg`) do Mercado Livre ou assets locais (`assets/produtos/...`).
